# hh-vacancy-monitor

Монитор вакансий hh.ru: собирает свежие вакансии по списку запросов, отсеивает мусор,
выгружает в Excel, присылает дайджест новых в Telegram и пишет сопроводительные письма
через LLM. Без API-ключа hh.ru — данные берутся из JSON, который hh.ru встраивает в
страницу поиска.

```
python -m hhmon run
23:44:00 INFO hhmon.hh_client: «n8n»: страница 1, 6 вакансий (всего 6)
23:44:01 INFO hhmon.hh_client: «автоматизация python»: страница 1, 44 вакансий (всего 44)
...
23:44:06 INFO hhmon: после фильтров: 42 вакансий
23:44:06 INFO hhmon: новых: 42
23:44:06 INFO hhmon: Excel: out\vacancies.xlsx
```

## Зачем

Искать работу руками — это каждый день открывать десять поисков и глазами вычёркивать
одно и то же. Здесь это делает скрипт по расписанию, а человеку остаётся открыть таблицу
или сообщение в Telegram, где только новое и уже отфильтрованное.

## Что умеет

- **Поиск** по нескольким запросам с фильтрами hh.ru (регион, удалёнка, опыт, занятость,
  «за последние N дней»); дубликаты по разным запросам склеиваются.
- **Фильтры**: стоп-слова в названии, минимальная зарплата, допустимый опыт, чёрный список
  компаний, отсечение «перегретых» вакансий с сотнями откликов.
- **Пометки** вместо удаления: однотипные объявления кадровых «центров», оплата в $ без
  опыта, 100k+ без опыта у непроверенной компании — такие строки подсвечены жёлтым.
- **Excel** с закреплённой шапкой, автофильтром, кликабельными ссылками и листом «Сводка»
  (по запросам, опыту, занятости); новые вакансии подсвечены зелёным. Плюс CSV.
- **SQLite-база**: помнит всё увиденное, поэтому дайджест содержит только новое;
  статусы `new / applied / skipped` и сохранённые письма.
- **Telegram-дайджест** новых вакансий (сообщения режутся по лимиту 4096 символов).
- **Сопроводительные письма** через любой OpenAI-совместимый API (OpenAI, DeepSeek,
  OpenRouter, локальная Ollama) на основе `profile.md` — без выдуманных навыков, промпт это
  явно запрещает.
- **Устойчивость**: повторы при сетевых ошибках, одна кривая запись или упавший запрос не
  останавливают остальные, «похожие» вакансии, которые hh.ru подмешивает при нулевой
  выдаче, отбрасываются.

## Установка

```bash
git clone https://github.com/<user>/hh-vacancy-monitor
cd hh-vacancy-monitor
python -m venv .venv && .venv\Scripts\activate    # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env                                # токены — только сюда
```

Python 3.11+ (используется `tomllib`). Зависимости: `requests`, `openpyxl`.

## Настройка

Всё в [`config.toml`](config.toml) — запросы, фильтры, пути, включение Telegram и LLM.
Секреты в `.env`:

```
TG_BOT_TOKEN=123456:ABC...   # бот из @BotFather
TG_CHAT_ID=123456789         # ваш chat_id (узнать у @userinfobot)
LLM_API_KEY=sk-...           # ключ OpenAI-совместимого API
```

Профиль для писем — [`profile.md`](profile.md): навыки, проекты, формат работы. LLM
использует только то, что там написано.

## Команды

| Команда | Что делает |
|---|---|
| `python -m hhmon run` | собрать → сохранить в базу → Excel/CSV → дайджест новых в Telegram → письма |
| `python -m hhmon run --notify-all` | прислать в Telegram всё, а не только новое |
| `python -m hhmon stats` | сколько вакансий в базе, по статусам и запросам |
| `python -m hhmon letters` | показать сгенерированные письма, чтобы вставить в отклик |
| `python -m hhmon mark applied 137196945 137538973` | отметить, что откликнулся |
| `python -m hhmon mark skipped 136996674` | больше не показывать |

## По расписанию

**Windows** — задача в планировщике каждый час:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\register-task.ps1
```

**Linux / macOS** — cron:

```
0 * * * * cd /path/to/hh-vacancy-monitor && .venv/bin/python -m hhmon run >> data/run.log 2>&1
```

## Как устроено

```
hhmon/
  hh_client.py    запрос страницы поиска, разбор <template id="HH-Lux-InitialState">, dataclass Vacancy
  filters.py      правила фильтрации и пометок, склейка дублей
  storage.py      SQLite: новые/старые, статусы, письма
  exporters.py    Excel (openpyxl) и CSV
  notify.py       Telegram Bot API
  cover_letter.py OpenAI-совместимый chat/completions
  config.py       config.toml + .env
  cli.py          подкоманды run / stats / letters / mark
tests/            15 тестов на фикстуре, повторяющей структуру страницы hh.ru; сеть не нужна
```

Почему не официальный API hh.ru: с 2024 года он требует регистрацию приложения и токен,
а страница поиска отдаёт тот же JSON без авторизации. Парсер держится за один тег и
падает с понятной ошибкой, если вёрстка изменится.

## Ограничения и планы

- hh.ru ограничивает частоту запросов: задержка 1.5 с между страницами, при капче —
  увеличить `delay_seconds`.
- Текст вакансии (обязанности/требования) не грузится — только карточка из выдачи. Для
  писем этого хватает; полный текст — следующий шаг.
- В планах: автоотклик через официальный API hh.ru с OAuth, источники Habr Career и FL.ru,
  веб-панель поверх базы.
