# Профиль кандидата (используется LLM для сопроводительных писем)

Данил, Санкт-Петербург, удалённая работа. Разработчик автоматизации: собираю рабочие
инструменты с помощью ИИ-ассистентов (Claude Code, Cursor) и доводжу их до продакшена.

Что умею и делал:
- Telegram-боты на Python (aiogram): запись клиентов, поддержка на LLM, уведомления.
- Парсеры и скрипты: сбор данных с сайтов (requests, BeautifulSoup, Playwright), выгрузка
  в Excel/Google Sheets (openpyxl, pandas, Google Sheets API), планировщики.
- Автоматизация бизнес-процессов: n8n / Make — вебхуки, интеграции CRM, таблиц, мессенджеров.
- Веб: HTML/CSS/JS, React/Next.js, Node.js; сайты на Tilda/WordPress, интеграции с Bitrix24.
- Инфраструктура: Git/GitHub, Linux/VPS, Docker; деплой ботов и сервисов 24/7.
- Excel/Google Sheets на продвинутом уровне: формулы, сводные, Apps Script.

Открытые проекты:
- hh-vacancy-monitor — монитор вакансий hh.ru с выгрузкой в Excel, Telegram-дайджестом и
  генерацией сопроводительных писем через LLM.
- tg-ai-support-bot — бот поддержки на aiogram + LLM с базой знаний и памятью диалога.
- n8n-lead-pipeline — конвейер заявок: вебхук → классификация LLM → таблица → Telegram.
